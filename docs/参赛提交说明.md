# 模型提交说明（参赛者）

## 一、准备
1. 浏览器打开：**http://<公网IP>/** （组织者下发的直连地址；国内速度快，没有 100 秒限制）
   （备用线路：**https://<cloudflare隧道地址>**（组织者下发），
   两个地址进度共享，中途切换不影响已传部分。）
   走备用线路时可能出现 `HTTP 524` 提示：**属正常现象**，页面会自动断开重连、
   从断点继续，放着等它走完即可，不要关页面、不要反复刷新。
2. 输入组织者发给你的**访问口令**，点「进入」。
3. 填写**队伍名称**（支持中文，1-64 字符，不能有空格、`/`、`\`）。

## 二、上传模型
- **PC（Windows/Mac）**：点「选择模型文件夹」，**选中整个模型文件夹**（选文件夹，不是选单个文件）。
- **手机端（微信/浏览器）**：手机上选不了文件夹（浏览器限制），点「添加文件」选择文件，
  **可以多次点击、累加选择**，把要提交的文件都加进下面的「已选文件」列表。
- 选完后页面会列出「已选文件」清单（文件名 + 大小），请核对；单个文件可点「移除」。
- 点「开始提交」后，列表里**所有文件会同时上传**（不是一个个排队传）。
- 页面显示：总进度条、**当前速度**、**预计剩余时间**，以及每个文件自己的进度和速度。
- 中途断网/关页面没关系：重进页面、输入同一口令、选**相同的文件夹/文件**，点「继续」即可从断点接着传，不用从头再来。

## 三、提交镜像（可选，可先跳过）
在你自己电脑上执行一行命令把镜像存成文件：
```
docker save -o 镜像名.tar 你的镜像名:标签
```
然后在页面选择「上传镜像 tar 文件」并选中这个 `.tar` 文件上传。

## 四、核对校验码
全部传完后点「完成提交」，页面会列出**服务端实际计算**的每个文件 SHA256 校验码，并可一键复制。
你在自己电脑上对同样的文件执行 `sha256sum 文件` 对比一致，就说明传对了、没传坏。
（复制出的内容也是 `sha256sum -c` 可用格式。）

## 注意
- 每个队伍**只能提交一次**；同名队伍会被拒绝，防止覆盖别人数据。
- 单文件 ≤ 100GB，单队总量 ≤ 200GB；磁盘不足时服务器会拒绝并提示。
- 超过 1GB 的大文件浏览器端不再预先算校验码（避免卡页面），改为上传完成后
  由服务端实算并列出，你本地 `sha256sum` 核对即可。
- 如果某文件一直失败，点它的「重试该文件」；仍不行请联系组织者。
